# Privacy Policy for ConvoVault: AI Chat Exporter

**Last Updated: March 24, 2026**

## Overview

ConvoVault: AI Chat Exporter is a browser extension that lets users export conversations from supported AI chat websites (ChatGPT, Gemini, Grok, and Claude AI) to local JSON files. This Privacy Policy explains how we handle your data.

## Data Collection and Usage

### What Data We Access

ConvoVault accesses the following data **only on the pages you visit**:

| Data Type | Purpose |
|-----------|---------|
| **Website Content** | Chat messages displayed on ChatGPT (chatgpt.com), Gemini (gemini.google.com), Grok (grok.com), and Claude AI (claude.ai) that you choose to export |
| **Browser Storage** | Local settings preferences (e.g., which metadata fields to include in exports) |

### How We Process Data

**All data processing is done locally on your device:**

1. The extension reads visible chat content from supported pages when you click the export button.
2. The extension builds JSON output on your device.
3. The extension copies JSON to your clipboard or downloads a local file to your computer.

**No exported chat data leaves your browser. No data is sent to external servers.**

### What We Do NOT Collect

We do **not** collect, store, or transmit:

- ❌ Personally identifiable information (name, email, address, age, ID numbers)
- ❌ Login credentials, passwords, or authentication tokens
- ❌ Financial or payment information
- ❌ Health information
- ❌ Location data or IP addresses
- ❌ Web browsing history beyond the current chat page
- ❌ User activity (keystrokes, clicks, mouse movements, scrolling)
- ❌ Personal communications (emails, texts, chat messages outside AI chats)

## Data Sharing

**We do not sell, share, or transfer any user data to third parties.**

No analytics, tracking, or advertising services are used.

## Permissions Justification

ConvoVault requests these permissions:

| Permission | Purpose |
|------------|---------|
| `storage` | Save local export preferences and user settings |
| Host permissions (`chatgpt.com/*`, `gemini.google.com/*`, `grok.com/*`, `claude.ai/*`) | Run only on these four supported domains |

## Security

Since all processing happens locally:

- ✅ Your chat data never leaves your computer
- ✅ No cloud services are involved
- ✅ You maintain full control over exported files
- ✅ No remote code execution

## Third-Party Services

ConvoVault does not integrate with or send data to any third-party services.

## Affiliation

ConvoVault is an independent open-source tool and is **not affiliated with, endorsed by, or connected to OpenAI, Google, xAI, or Anthropic**.
